# 🌐 Curso HTML

Este repositório reúne os arquivos desenvolvidos durante um **mini curso introdutório de HTML**, com o objetivo de aprender os conceitos fundamentais da linguagem de marcação utilizada na construção de páginas web.

O projeto representa meu primeiro contato com o desenvolvimento web, abordando a estrutura básica de documentos HTML e os principais elementos utilizados na criação de páginas.

## 🚀 Objetivos

* Compreender a estrutura de um documento HTML.
* Aprender as principais tags da linguagem.
* Desenvolver páginas web simples.
* Praticar os fundamentos do desenvolvimento front-end.

## 📚 Conteúdos abordados

Durante o curso foram estudados tópicos como:

* Estrutura básica de uma página HTML
* Títulos e parágrafos
* Links
* Imagens
* Listas ordenadas e não ordenadas
* Tabelas
* Formulários
* Divs e organização de conteúdo
* Boas práticas na estruturação de páginas

## ▶️ Como visualizar

1. Clone o repositório:

```bash
git clone https://github.com/Cmelodev/Curso-HTML.git
```

2. Entre na pasta do projeto:

```bash
cd Curso-HTML
```

3. Abra qualquer arquivo `.html` em um navegador ou utilizando a extensão **Live Server** no Visual Studio Code.
